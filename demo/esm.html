README and API

Load the component from esm.sh

This example imports the published component class from esm.sh and registers it manually. Both fieldsets remain available if the CDN cannot load. The import is pinned to the package version and is updated by the version script. 

import { FormFieldsetProgressElement } from
  'https://esm.sh/@aarongustafson/form-fieldset-progress@0.1.1/form-fieldset-progress.js?bundle&target=es2022';

customElements.define(
  'form-fieldset-progress',
  FormFieldsetProgressElement,
);
